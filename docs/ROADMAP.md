# ROADMAP

Registro de pendencias deliberadas. Itens deste arquivo nao devem ser implementados automaticamente sem pedido do usuario.

## Pendencias abertas

- Continuar o desenvolvimento do aplicativo a partir do estado consolidado em `ESTADO.md`.
- Manter auditorias de regressao para desktop, mobile e PWA conforme novas funcionalidades forem incorporadas.
- Manter o Reader PDF e a Biblioteca sob testes automatizados a cada alteracao.

## Como registrar

Use o gatilho `registre como pendencia`. Sempre que possivel, atribuir um ID `APP-XXX`, descricao, motivo, prioridade e dependencias.
